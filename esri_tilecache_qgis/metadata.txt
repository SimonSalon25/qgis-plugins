qgisMinimumVersion=3.34
description=Convert Esri tile caches (.tpk incl. Compact V1, .tpkx, cache folders, LERC elevation, .vtpk) to GeoPackage and MBTiles without re-encoding tiles.
about=GDAL cannot read the older Compact V1 tile packages (.tpk) still used by some national mapping agencies. This plugin converts Esri tile caches to open formats: image tiles are copied byte for byte into a GeoPackage (no quality loss, all levels kept, fast multi-threaded overviews); LERC elevation caches become a float32 2D gridded coverage; vector tile packages (.vtpk, Web Mercator) become MBTiles. Damaged and invalid tiles are skipped and reported. Processing algorithms in the "Esri tile cache" provider. Dependencies: numpy and Pillow (included with QGIS) for overviews; the optional Python package "lerc" for LERC elevation caches. Developed with an AI assistant under the direction of the author; method, tests and AI disclosure in the repository.
